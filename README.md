# 수학 놀이터 (math1)

초등 1~3학년이 만화와 게임으로 수학 원리를 익히는 정적 웹앱입니다. GitHub Pages에 그대로 올릴 수 있습니다.

## 기능

- **오늘의 미션**: 학년에 맞는 게임 3개가 매일 바뀝니다. 별 1개 이상이면 완료되고 미션마다 코인 보너스를 줍니다.
- **만화로 배우기**: 이야기 속 질문에 답하며 원리를 스스로 찾는 레슨 5개(묶어서 세기, 가르기와 모으기, 받아올림 덧셈, 곱셈의 의미, 똑같이 나누기). 틀리면 힌트 장면을 보고 다시 풉니다.
- **연습 게임 14종**: 수 세기, 크기 비교, 10까지 덧셈·뺄셈, 10 만들기, 꼭짓점 세기, 받아올림·받아내림, 곱셈구구, 뛰어 세기, 시계 보기, 나눗셈, 두 자리 곱셈, 분수. 문제는 매번 새로 만들어집니다.
- **보상**: 별(최고 기록), 코인, 연속 학습 일수, 코인으로 모으는 스티커북.
- **설정**: 이름, 학년, 효과음, 문제 읽어 주기(한국어 음성), 기록 초기화.

진행 기록은 브라우저 `localStorage`에만 저장되며, 저장이 막혀 있어도 앱은 동작합니다.

## 로컬에서 실행

`file://`로 열면 데이터 파일을 읽지 못하므로 정적 서버로 엽니다.

```bash
python -m http.server 8000
# http://localhost:8000
```

## 테스트

```bash
npm test
```

## 레슨 추가

`data/steps/<id>.json`을 만들고 `data/steps/index.json`의 `steps`에 id를 넣습니다. 장면 그림은 `image`(SVG 경로) 또는 `visual`(이모지 글자) 중 하나를 씁니다. 형식은 `js/engine.js`의 `validateStep`이 검사합니다.
